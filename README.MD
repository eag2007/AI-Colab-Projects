# Обучающие проекты по искусственному интеллекту

Репозиторий содержит учебные проекты, выполненные в рамках изучения методов машинного обучения и статистического анализа. Проекты реализованы в среде Google Colab.

### Темы
- Логистическая регрессия
- Линейная регрессия
- Линейные модели машинного обучения
- Доверительный интервал
- Нейронные сети и их модели

## Период обучения
2024-2025 год

## Файлы

### ```AI_bank.ipynb```
Предсказание того, какой банк выберет клиент. Задача бинарной классификации с использованием логистической регрессии. Включает предварительный анализ данных, визуализацию, построение модели и оценку качества предсказаний.

Основные этапы:
- Загрузка и исследование данных (информация о клиентах, их доходах, возрасте и т.д.)
- Визуализация распределений признаков
- Разделение данных на обучающую и тестовую выборки
- Обучение модели логистической регрессии
- Оценка точности модели (accuracy, confusion matrix)
- Анализ важности признаков

### ```AI_predict_the_score.ipynb```
Предсказание балла/оценки с использованием линейной регрессии. Задача регрессионного анализа для прогнозирования числового значения на основе входных параметров.

Основные этапы:
- Импорт и предобработка данных
- Корреляционный анализ признаков
- Разделение на train/test выборки
- Построение и обучение модели линейной регрессии
- Расчет метрик качества (R², MSE, MAE)
- Построение доверительных интервалов для прогнозов
- Визуализация результатов: реальные vs предсказанные значения

### ```AI_calculate_confidence_intervals.ipynb```
Расчет и визуализация доверительных интервалов. Статистический анализ данных с демонстрацией концепции доверительных интервалов.

Основные этапы:
- Генерация или загрузка выборочных данных
- Расчет выборочного среднего и стандартного отклонения
- Построение доверительных интервалов для среднего значения
- Визуализация интервалов с использованием библиотек matplotlib/seaborn
- Интерпретация полученных результатов

### ```AI_neural_network_models.ipynb```
Изучение и построение моделей нейронных сетей. Введение в глубокое обучение с использованием PyTorch или TensorFlow/Keras.

Основные этапы:
- Создание простой полносвязной нейронной сети
- Настройка архитектуры: входной слой, скрытые слои, выходной слой
- Выбор функций активации (ReLU, Sigmoid, Softmax)
- Компиляция модели: выбор оптимизатора и функции потерь
- Обучение модели на данных
- Визуализация процесса обучения (графики loss и accuracy)
- Оценка качества на тестовых данных

## Библиотеки
В проектах используются следующие библиотеки:

| Библиотека | Назначение |
|-----------|------------|
| `pandas` | Обработка и анализ табличных данных |
| `numpy` | Работа с многомерными массивами и математические операции |
| `matplotlib` | Базовая визуализация данных (графики, диаграммы) |
| `seaborn` | Статистическая визуализация данных |
| `scikit-learn` | Алгоритмы машинного обучения, предобработка данных, метрики |
| `scipy.stats` | Статистические функции и распределения |
| `torch` / `tensorflow` | Фреймворки для глубокого обучения |
| `plotly` | Интерактивная визуализация данных |
